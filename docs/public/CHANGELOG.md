# 版本记录

## 1.2.0-beta12 · 本地测试候选

- 选机设置新增「验机报告筛选」，按转转报告顺序提供外观、电池情况、屏幕、设备功能与维修浸液。指定模式只核验所选项，全部通过核验报告的适用项目。
- 基础条件之后依次核验维修浸液、屏幕、设备功能、电池、外观。缺失或冲突的必要字段列为待确认，可在「筛选核验记录」查看原因。
- 已保存的旧设置保留原筛选范围。首次配置默认电池未检出更换、屏幕显示和触控全部通过、设备功能全部通过、维修浸液全部通过，外观不限。

## 1.2.0-beta11 · GitHub 预发布

- 新增默认关闭的「允许自动确认换新电池提醒」。同时开启自动收藏时，插件会在同一商品的换新电池弹窗上点击一次「知道了，继续收藏」。
- 收藏请求成功后独立回读，只有确认已收藏才计入成功。无法确认的商品保留在命中记录中。

## 1.2.0-beta10 · 本地测试候选

- 新增“命中后继续扫描”选项。选机设置中的“命中记录”可回看最近 10 次有命中的任务，按收藏状态筛选并打开详情。
- 检测收藏后实际出现的“知道了，继续收藏”按钮，将商品标记为需手动确认。收藏请求失败、回读未收藏和回读未返回分别记录原因。
- 连续扫描模式先保存命中，收藏结算后再处理下一件。保留手动暂停和任务上限。

## 1.2.0-beta9 · 收藏收尾修复测试包

- 收藏核验结束后收尾全局等待；未知状态商品按 ID 在当前 App 进程内隔离，不因超时重新点击，可继续其他商品。旧响应不解除另一件商品的等待。
- 命中待确认商品查看详情后返回，仅重新读取收藏状态；确认已收藏时更新原记录与计数，不重复添加结果，不再点击收藏。
- 新增最近 40 条收藏阶段诊断，基础诊断不含商品 ID，不保存原始请求、Cookie 或 Token。
- 保留 beta8 设置保存修复。用户已反馈 beta9 运行及收藏可用，提供本版安装文件；不扩大为所有环境与路径均已验证，电池二次确认仍未自动处理。

## 1.2.0-beta8 · 设置保存修复测试包

- 修复仅打开自动收藏、关闭设置再进入时恢复旧值的问题；开启与关闭均会保存。型号、iOS 范围与扫描限制等条件一并保存。
- 点击关闭时先校验；无效设置可继续编辑或放弃修改，不覆盖上次有效配置。禁止下滑直接关闭设置页，避免绕过校验和保存。
- 保存配置与启动任务分离；关闭设置不发起搜索或收藏，不改变已有任务的启动条件。
- 保留 beta7 的悬浮入口拖动及此前修复；平台换新电池收藏二次确认仍未自动处理。此包为本地测试候选，尚未发布 GitHub。

## 1.2.0-beta7 · 悬浮按钮拖动测试包

- “选机设置”入口支持拖动，保存相对位置，限制在屏幕安全区域，定时挂载和页面切换不会重置位置。
- 拖动入口不被当作操作商品列表；正常点击入口仍使用原有设置/任务入口逻辑。
- 本版未自动处理平台换新电池等收藏二次确认；收藏仍需接口成功与独立状态回读，不能把点击收藏或关闭提示当作成功。
- 保留 beta6 紧凑等高选项及此前键盘、布局与翻页修复。通过本地构建、逻辑与模拟器检查，提供 GitHub 预发布安装文件；真实转转页面仍待真机验证。

## 1.2.0-beta6 · 紧凑选项测试包

- 保留此前输入体验、顶部布局和翻页修复，多选逻辑保持不变。此包暂未发布到 GitHub Releases，实际转转页面仍待真机验证。

## 1.2.0-beta2 · 翻页修复测试包（尚待真机验证）

- 修正列表到底部后仍重复设置相同滚动位置的行为。识别到归属当前列表的底部加载控件时调用其加载入口，同页最多一次，并等待实际请求及返回。
- 识别加载中与“没有更多”状态；入口未知或存在多个候选时明确暂停，避免反复空滚。未经识别的自定义控件仍需继续适配。
- 诊断新增列表偏移、内容高度、视口高度、底部控件类型及状态、翻页过程记录，不包含新增商品明细或鉴权字段。
- 用户报告已确认 beta1 第一页处理20件后没有第二页请求，而相同条件下手动上拉能加载更多；该证据尚不能证明 beta2 已覆盖真实页面的控件。

此包仅用于替换测试，未覆盖或替换 GitHub 已发布的 beta1 附件。

## 1.2.0-beta1 · 社区免费试用准备版

- 提供 TrollFools、rootless、RootHide 分发文件，以及源码包、分发合集与 SHA-256 校验文件。
- 新用户自动收藏默认关闭；已有保存的开启或关闭值保留，升级后应主动核对。
- 新增任务上限：默认处理 100 件、有效运行 15 分钟；件数范围 1–2000，分钟范围 1–120。暂停和查看详情不计时，触及任一上限暂停且需新建任务；已发出的收藏先完成核验与回读。
- 新增全局停用，停止任务与采集，保留设置入口和已有结果，不撤回已发出的收藏。
- 增加首次使用帮助与环境信息，显示硬件型号代码、系统、App、插件版本、编译变体和基线；非基线或无法识别 App 版本时需用户明确确认。
- 诊断默认不含商品明细，详细诊断需主动选择；导出先预览，再由用户调用系统分享。无外部上传服务器或自动发布。
- 延续购买渠道七项多选、默认国行，按 iOS → 渠道 → 容量 → 成色核验；只读验机报告字段，未知或冲突保持待确认。

本版新增功能和渠道筛选仍需真机验收，rootless / RootHide 加载、连续翻页、自动收藏及成功回读尚未获得真机通过证据。详细范围见[兼容说明](compatibility.md)。
