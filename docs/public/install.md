# 安装与使用 · 2.0.0-alpha1

这是第二版 D2 本地真机测试候选，未正式发布，与转转官方无关。无需付费、另行注册或插件服务器。先阅读[兼容说明](compatibility.md)，保留你手头可用的旧安装包，确认能恢复后再替换。

## 选择安装文件

| 使用环境 | 文件 | 安装方式 |
|---|---|---|
| TrollFools | `ZZPicker-2.0.0-alpha1-trollfools.dylib` 或 `ZZPicker-2.0.0-alpha1-trollfools.zip` | 在 TrollFools 中选择转转，导入其中一种文件并注入 |
| rootless 越狱 | `ZZPicker-2.0.0-alpha1-rootless.deb` | 用对应环境的包管理器安装 |
| RootHide 环境 | `ZZPicker-2.0.0-alpha1-roothide.deb` | 用该环境的包管理器安装，并按环境规则允许转转加载 |

`ZZPicker-2.0.0-alpha1-release.zip` 为分发合集，包含各安装格式、文档与校验清单；`ZZPicker-2.0.0-alpha1-source.zip` 为源码，不是手机安装包。使用 `SHA256SUMS` 核对单个文件；合集本身使用 `ZZPicker-2.0.0-alpha1-release.zip.sha256` 核对。文件名或校验不一致时重新取得完整原包。

同一转转 App 只装一种 ZZPicker。先结束任务、完全关闭转转，移除原注入或原包，再安装对应的新文件，最后重开转转。插件不会扩大注入工具支持的设备或系统范围；rootless、RootHide 包尚无本项目真机加载结论。

安装工具的当前支持范围与操作以官方说明为准：[TrollFools](https://github.com/Lessica/TrollFools)、[Dopamine](https://github.com/opa334/Dopamine)、[RootHide 开发说明](https://github.com/roothide/Developer)。无需 HTTP Catcher、抓包证书、账号密码或旧请求签名。

## 首次使用

1. 在转转首页或商品列表打开“选机设置”，阅读首次使用帮助，在“说明 / 环境”核对设备型号代码、iOS、转转、插件版本和编译变体。设备型号代码不是 UDID 或设备名称。基线为转转 12.8.5；非基线或无法识别 App 版本时，必须由你明确确认后才能启动。
2. 选择待售手机型号与用途。新用户默认 15 Pro Max、自动范围、两用途关闭；“可安装巨魔 / 可完整越狱”同时开启时取交集。手动上下限含端点，仅收窄实际范围，留空不取消用途限制。手工改写机型后容量列表可能需重开设置或在机型选择器确认一次，建议直接用选择器。先看“实际候选范围”和“支持依据”，不要只看最低 / 最高两端。购买渠道默认国行，可选国行、美版、港澳台版、韩版、日版、欧版、其他版本。渠道、容量、成色均支持多选，同一组内任一满足即可，组内全不选表示不限；不同条件组需同时满足。
3. 首轮保持自动收藏关闭，建议最多处理 5 件、有效运行 2 分钟。新用户默认关闭，升级保留以前保存的开启或关闭值，不会一律改成关闭。设置本次最多处理件数和有效运行分钟数：默认 100 件、15 分钟，可选范围分别为 1–2000 件和 1–120 分钟。
4. 从首页开始搜索并扫描，或从列表应用条件重新搜索。插件先操作转转原生搜索及容量、成色筛选并确认结果，再读取验机报告。保持转转前台；切出 App、锁屏或干预原页面会暂停。
5. 核对型号与销售状态后，按系统范围、购买渠道、容量、成色及所选用途逐项核验。新用途需要报告机型；Beta / RC 排除，必要字段冲突或缺失为待确认。17.0 缺构建号的 D2 政策见兼容说明。渠道只读验机报告，不从标题猜测；受限字段缺失、未知或冲突时列为待确认，不自动收藏。报告中的“其他版本”不等同未知渠道。
6. 命中后暂停。可查看详情，返回后手动继续，或直接继续扫描。暂停 / 查看详情不计入有效运行时间。处理件数按逐件处理计数，不是搜索加载数或命中数；达到件数或时间任一上限后不能继续原任务，需新建任务。

选择新机型不会静默清空容量：例如从 14 Pro 的 128G 切到 15 Pro Max，128G 保留并提示冲突，需主动取消或改选；无交集、待收录或规则不可用时不能开始。可重载本地规则，不联网更新。

中央任务窗可收起。搜索加载数按商品去重；明确结论、待确认与命中分别呈现。未知报告不作为命中。“核验记录”包含全部商品，可按符合 / 不符合 / 待确认筛选；详情展示同一次判定的全部条件与冻结依据。收藏待确认单独标记，不会改变兼容性结论。加载或页面操作失败时保留队列并暂停，不把点击已发送当成操作成功。翻页、恢复及隐藏采集仍需社区真机验证。

## 收藏与停止

启用自动收藏后，只对确认命中且未收藏的商品尝试操作原页面收藏控件，回读已收藏才记录成功；原有收藏不应被取消。失败、状态不明或回读失败会显示待确认，不重复点击。**本版自动收藏及成功回读尚无真机完成证据**，建议在只读验证后单独测试一件并手动核对。

暂停或触及上限时，已发出的收藏仍须完成核验与回读，再处理后续动作。不要在收藏状态未确认时反复启动任务；长期没有返回时，完全关闭并重开转转，先手动检查收藏。

“结束”停止本次任务并保留结果；“全局停用”停止任务与采集，设置入口和结果仍可查看。重新启用后需主动启动任务。两者都无法撤回已经发出的收藏，已有收藏由你在转转内管理。

如果在收藏请求处理中结束或停用，结果可能保留为待确认，并阻止新任务重复操作。重新启用不会自动重试；若始终没有返回，请完全重开转转后先手动核对该商品的收藏状态。

## 更新、回退与卸载

本版仅通过你手动取得安装包、核对校验并替换来更新，不连接外部更新服务器。更新前结束任务并保存需要的结果，升级后核对设置与自动收藏开关。

有效旧设置自动迁移到 `com.codex.zzpicker.config.v3`（schemaVersion 3），原 config.v2 / config.v1 不删除。旧型号文字、原始手动边界、容量 / 成色 / 渠道、收藏开关与限额保持，两新用途关闭；未主动重选型号或自动模式时，普通手动筛选保留旧数值语义，包括两端均空。主动选择新机型或自动模式后才采用新机型边界。

存在但损坏的高优先级设置不会静默退回旧值。进入“恢复设置”查看旧备份预览，再确认恢复旧设置或使用默认设置；取消不写入、不开始任务。确认后先保留损坏原文的本地备份，再写新设置并回读；失败时保留原状态。损坏原文不进入诊断导出。

关闭设置保存格式合法的下一次配置，无交集也可暂存但不能开始；格式错误需继续编辑或放弃修改。旧任务仍用旧配置与规则快照，关闭设置不会自动继续。新任务替换前需确认，校验或保存失败保留旧任务；收藏处理中仍禁止重复启动。

需要回退时，移除本版，再安装自己保留的旧包。旧包继续读取旧键，第二版新修改不会自动写回旧键；未来重装第二版时有效 v3 仍优先。旧包也可能是测试版，不能视为稳定版。

TrollFools 用户在转转的插件管理中移除 ZZPicker；deb 用户用对应包管理器卸载。然后完全关闭并重开转转。卸载不会取消已有收藏。异常反馈请看[反馈说明](feedback.md)。
