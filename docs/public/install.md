# 安装与使用 · 1.2.0-beta9

这是转转选机助手的社区免费试用版，与转转官方无关。无需付费、另行注册或插件服务器。先阅读[兼容说明](compatibility.md)，保留你手头可用的旧安装包，确认能恢复后再替换。

**目前仅使用 TrollFools 注入 `.dylib` 文件完成真机测试。** 压缩包直接导入、rootless deb、RootHide deb 等其他格式或方式需自行测试。长时间运行会导致手机发热，介意请勿使用。实际环境和四张截图见 [README 真机实践](../../README.md#真机实践)。

## 选择安装文件

| 使用环境 | 文件 | 安装方式 |
|---|---|---|
| TrollFools | `ZZPicker-1.2.0-beta9-trollfools.dylib` 或 `ZZPicker-1.2.0-beta9-trollfools.zip` | 在 TrollFools 中选择转转，导入其中一种文件并注入 |
| rootless 越狱 | `ZZPicker-1.2.0-beta9-rootless.deb` | 用对应环境的包管理器安装 |
| RootHide 环境 | `ZZPicker-1.2.0-beta9-roothide.deb` | 用该环境的包管理器安装，并按环境规则允许转转加载 |

`ZZPicker-1.2.0-beta9-release.zip` 为分发合集，包含各安装格式、文档与校验清单；`ZZPicker-1.2.0-beta9-source.zip` 为源码，不是手机安装包。使用 `SHA256SUMS` 核对单个文件；合集本身使用 `ZZPicker-1.2.0-beta9-release.zip.sha256` 核对。文件名或校验不一致时重新取得完整原包。

同一转转 App 只装一种 ZZPicker。先结束任务、完全关闭转转，移除原注入或原包，再安装对应的新文件，最后重开转转。插件不会扩大注入工具支持的设备或系统范围；rootless、RootHide 包尚无本项目真机加载结论。

安装工具的当前支持范围与操作以官方说明为准：[TrollFools](https://github.com/Lessica/TrollFools)、[Dopamine](https://github.com/opa334/Dopamine)、[RootHide 开发说明](https://github.com/roothide/Developer)。无需 HTTP Catcher、抓包证书、账号密码或旧请求签名。

## 首次使用

1. 在转转首页或商品列表打开“选机设置”，阅读首次使用帮助，在“说明 / 环境”核对设备型号代码、iOS、转转、插件版本和编译变体。设备型号代码不是 UDID 或设备名称。基线为转转 12.8.5；非基线或无法识别 App 版本时，必须由你明确确认后才能启动。
2. 输入完整型号，设置待售手机的 iOS 上下限（含端点，留空不限）。购买渠道默认国行，可选国行、美版、港澳台版、韩版、日版、欧版、其他版本。渠道、容量、成色均支持多选，同一组内任一满足即可，组内全不选表示不限；不同条件组需同时满足。
3. 首轮保持自动收藏关闭。新用户默认关闭，升级保留以前保存的开启或关闭值，不会一律改成关闭。设置本次最多处理件数和有效运行分钟数：默认 100 件、15 分钟，可选范围分别为 1–2000 件和 1–120 分钟。
4. 从首页开始搜索并扫描，或从列表应用条件重新搜索。插件先操作转转原生搜索及容量、成色筛选并确认结果，再读取验机报告。保持转转前台；切出 App、锁屏或干预原页面会暂停。
5. 核对型号与销售状态后，按 iOS → 购买渠道 → 容量 → 成色核验。渠道只读验机报告，不从标题猜测；受限字段缺失、未知或冲突时列为待确认，不自动收藏。报告中的“其他版本”不等同未知渠道。
6. 命中后暂停。可查看详情，返回后手动继续，或直接继续扫描。暂停 / 查看详情不计入有效运行时间。处理件数按逐件处理计数，不是搜索加载数或命中数；达到件数或时间任一上限后不能继续原任务，需新建任务。

中央任务窗可收起。搜索加载数按商品去重；明确结论、待确认与命中分别呈现。未知报告不作为命中。加载或页面操作失败时保留队列并暂停，不把点击已发送当成操作成功。本次已有 beta9 扫描与收藏的真机记录；更多页面布局、超时恢复和长任务稳定性仍需分别验证。

“选机设置”悬浮按钮可直接拖动，位置会保留并限制在屏幕安全区域，轻点仍打开原入口。

修改设置后点右上角“关闭”会校验并保存，不需要先开始扫描。设置不合法时，可选择“继续编辑”或“放弃修改”；放弃修改保留原来已保存的条件。设置页禁止下滑直接关闭，防止绕过保存。已有任务沿用开始时的条件，新设置用于下一次任务。

## 收藏与停止

beta11 的安装文件见 [GitHub 预发布](https://github.com/bingdilian/zz-picker-public/releases/tag/v1.2.0-beta11)，下载 TrollFools 压缩包并解压出 `ZZPicker.dylib`。在 beta9 中，平台换新电池提醒需要手动确认。使用 beta11 时，可同时开启「自动加入收藏」与「允许自动确认换新电池提醒」。要在等待结束后继续扫描，再打开「命中后继续扫描」。

beta9 会在收藏核验结束后解除全局等待。无法确认的商品按 ID 在当前 App 进程内隔离，不再自动点击收藏，但可继续扫描其他商品；结束任务或新建任务不会清除隔离。完全重开 App 会清除内存记录，因此重开前后都应先手动核对未知商品。

命中商品显示“收藏待确认”时，可查看详情并手动核对或收藏，返回列表后插件自动进行一次只读核验；仍未知时不重复计数、不重试收藏。确认成功后更新原命中记录，继续扫描仍需手动点击。

启用自动收藏后，只对确认命中且未收藏的商品尝试操作原页面收藏控件，回读已收藏才记录成功；原有收藏不应被取消。失败、状态不明或回读失败会显示待确认，不重复点击。**用户已反馈 beta9 收藏可用；其他环境与商品路径仍需单独验证**，建议在只读验证后单独测试一件并手动核对。

暂停或触及上限时，已发出的收藏仍须完成核验与回读，再处理后续动作。不要在收藏状态未确认时反复启动任务；长期没有返回时，完全关闭并重开转转，先手动检查收藏。

“结束”停止本次任务并保留结果；“全局停用”停止任务与采集，设置入口和结果仍可查看。重新启用后需主动启动任务。两者都无法撤回已经发出的收藏，已有收藏由你在转转内管理。

如果在收藏请求处理中结束或停用，结果可能保留为待确认，并阻止新任务重复操作。重新启用不会自动重试；若始终没有返回，请完全重开转转后先手动核对该商品的收藏状态。

## 更新、回退与卸载

本版仅通过你手动取得安装包、核对校验并替换来更新，不连接外部更新服务器。更新前结束任务并保存需要的结果，升级后核对设置与自动收藏开关。

需要回退时，移除本版，再安装你自行保留的旧包；旧包也可能是测试版，不能视为稳定版，且新旧配置不保证完全互通。

TrollFools 用户在转转的插件管理中移除 ZZPicker；deb 用户用对应包管理器卸载。然后完全关闭并重开转转。卸载不会取消已有收藏。异常反馈请看[反馈说明](feedback.md)。
