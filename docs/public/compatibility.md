固定软件资料为 [TrollStore 2.1.1](https://github.com/opa334/TrollStore/releases/tag/2.1.1)、[TrollRestore 指定提交](https://github.com/JJTech0130/TrollRestore/tree/082f2520556b9aa8e2b8d6661b81a954ee35966b)、[Dopamine 3.0.11](https://github.com/opa334/Dopamine/releases/tag/3.0.11)。TrollRestore 路径需要电脑，已收录 15.2～16.6.1 与 17.0，按机型下限再相交。其他安装路径与前提在“支持依据”中查看；插件不会执行巨魔安装或越狱，不推测未来升级或降级后的能力。

明确 Beta / RC 以及已知 RC 构建 20H18 在新能力路径中排除。已收录构建与报告版本矛盾（例如21A329搭配16.5）也列为待确认，不因所选工具没有构建谓词而忽略；此一致性检查不扩张为16.x完整固件白名单。纯数字版本的发行通道仍为“未独立验证”，不能据此保证它是真实正式固件。新能力必须有报告机型，不能靠商品标题回退放行；报告与标题冲突或必要字段缺失列为待确认。明确不符优先，但详情保留其他未知原因。

## 本地检查与真实证据

本候选的 Node 逻辑、macOS JavaScriptCore / Foundation、iOS 模拟器原生界面、包布局 / 签名 / 内嵌模块均纳入本地验收。模拟器使用插件测试宿主，并未运行真实转转；合成 P01～P22 报告不能当作真实手机报告样本。

真实证据仍只有旧 test5 在 iPhone 13 Pro Max / iOS 15.4.1 / TrollFools 的一次部分流程：最终搜索包含 512G 与 99新，加载 20 件、处理 4 件、排除 3 件、命中 1 件，自动收藏关闭后由用户结束。报告 iOS 27 是商品报告值，不是运行手机的系统。它不能扩展为第二版全流程通过。

第二版真机验收仍待验证；rootless / RootHide 加载也待验证。具体包括四款真实报告来源、渠道 / 构建冲突、升级与重启迁移、键盘与暂停恢复、连续翻页、较长任务、单次自动收藏及独立成功回读。

分页只对归属当前列表且唯一的已识别入口调用加载；未知入口暂停并保留诊断。自动收藏只对全部条件明确符合的未收藏商品尝试一次，成功必须独立回读确认，未知不重复点击。达到件数或有效时长上限暂停并需新建任务，已发出的收藏不能撤回。

购买渠道七项多选，默认国行，同组 OR、跨组 AND；限定渠道时只读验机报告，缺失或冲突待确认。App 页面、报告字段或工具环境变化仍可能导致暂停或需适配。请先关闭自动收藏做小范围只读测试，反馈见[说明](feedback.md)。

## 已知界面限制

手工改写型号文字后，容量选项可能仍显示进入设置时的列表；可通过“选择已收录机型”确认一次，或关闭重开设置刷新。首轮测试建议直接使用机型选择器。已选容量仍保留，实际冲突校验继续生效。

如果运行时模块缺失或脚本异常，设置页仅提供初始化诊断入口，保留原设置且禁止保存 / 启动；重新安装完整包后再检查。仅能力规则数据不可用、普通筛选模块仍完整时，可关闭用途走可用的普通路径。
