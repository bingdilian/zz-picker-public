# ZZPicker development

- The development and release source of truth is `bingdilian/zz-picker-public`.
- Maintain v1 on `v1-compatibility` and v2 on `v2-compatibility`. Work in the repository root; do not introduce parallel `v1/` or `v2/` source trees.
- Check the branch and working tree before editing. Preserve uncommitted work when switching.
- Use a GitHub noreply commit email. Never import legacy repository history or local privacy backups.
- `build/` and `dist/` are ignored local files shared by branch switches. Do not upload captures, credentials, private diagnostics, or local reference archives.
- See `docs/public/development.md` for build and branch instructions. V2 has no published installation release.
